# Endpoints de API

*No Aplica.*

**Xanezu Catch** es una aplicación completamente cliente, autoejecutable tanto en web como en Electron, que no depende de servidores externos ni APIs REST para su funcionamiento básico. Todo el procesamiento de datos, físicas y renderizado se realiza localmente en el dispositivo del usuario. El progreso se persiste localmente a través de las APIs estándar del navegador (`localStorage`).\n
