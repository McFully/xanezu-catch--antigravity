# GUÍA DE INSTALACIÓN Y ARRANQUE LOCAL

## 1. REQUISITOS PREVIOS
- Node.js (versión 18+ o LTS recomendada)
- Gestor de paquetes: `npm`, `pnpm` o `yarn`

## 2. PASO A PASO DE INICIALIZACIÓN
```bash
# 1. Clonar o acceder al directorio del proyecto
cd "E:\Proyectos Antigravity\Juegos\Juego XANEZU CATCH  ANTIGRAVITY"

# 2. Instalar dependencias
npm install

# 3. Iniciar entorno de desarrollo
npm run dev # O abrir index.html si es proyecto estático
```
