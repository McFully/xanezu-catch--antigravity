# 🎮 Xanezu Catch - Guía de Instalación

¡Bienvenido a la experiencia definitiva de Xanezu Catch! Esta guía te ayudará a instalar el juego en tu sistema Windows paso a paso.

## 📋 Requisitos del Sistema

- **Sistema Operativo:** Windows 10 o Windows 11 (Recomendado).
- **Espacio en Disco:** ~150 MB libres.
- **Gráficos:** Soporte para WebGL (Prácticamente cualquier PC moderno).

## 🚀 Pasos para la Instalación

### 1. Obtener el instalador

Busca el archivo **`XanezuCatch-Setup-1.5.0.exe`** en la carpeta de descargas o en el directorio `dist` del proyecto una vez compilado.

### 2. Ejecutar el Instalador

Haz doble clic en el archivo `.exe`. Si Windows muestra una advertencia de "SmartScreen" (ya que el ejecutable no está firmado digitalmente), sigue estos pasos:

- Haz clic en **"Más información"**.
- Selecciona **"Ejecutar de todas formas"**.

### 3. Configuración de la Instalación

El instalador es de estándar profesional y te guiará por las siguientes ventanas:

- **Selección de Idioma:** Escoge el idioma preferido para el instalador.
- **Ubicación de Instalación:** Por defecto se instalará en `AppData\Local\Programs\mx-catch`, pero puedes cambiarlo.
- **Accesos Directos:** El instalador creará un acceso directo en tu Escritorio y en el Menú de Inicio automáticamente.

### 4. Lanzamiento del Juego

Una vez terminada la instalación, puedes:

- Marcar la casilla **"Lanzar Xanezu Catch"** al finalizar el instalador.
- O usar el acceso directo con el icono de la rana 🐸 en tu escritorio.

## 🛠️ Resolución de Problemas

- **Pantalla Negra:** Asegúrate de tener los drivers de video actualizados. El juego requiere aceleración por hardware.
- **Error al Guardar:** El ejecutable guarda el progreso localmente en tu perfil de usuario. Asegúrate de tener permisos de escritura.
