# Assets: Menu & UI

Este directorio contiene todos los recursos visuales y auditivos relacionados con la interfaz de usuario, navegación y elementos globales del juego.

## Contenido

- `OBJETOS-BASE/`: Modelos y SVGs universales (monedas, bananas, premios).
- `audio/`: Música de menú y efectos de sonido de botones.
- `fondo/`: Fondos decorativos para las pantallas de inicio y selección.
- `*.svg`: Iconos de la barra lateral (achievements, shop, settings).
- `favicon_frog.ico`: Icono de la aplicación.

## Reglas de Adición

1. Los iconos nuevos de UI deben subirse en formato `.svg`.
2. Los fondos pesados deben convertirse a `.webp` para optimizar la carga inicial.
