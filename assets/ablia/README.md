# Assets: ABL_IA (Neural Mode)

Directorio para los recursos del modo de aprendizaje automático (Adaptive Biome Learning).

## Formato de Carpetas

`NUMERO -Titulo-del-Capitulo`

Ejemplo: `1 -Jungla-Tropical`

## Particularidades

- Los personajes en este modo pueden ser generados procedimentalmente, por lo que la carpeta `personaje` puede contener esquemas de color o descriptores IA.
- Los obstáculos suelen ser variantes tecnológicas de los de campaña.
