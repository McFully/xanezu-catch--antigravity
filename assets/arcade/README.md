# Assets: Arcade Mode (8-bit)

Recursos exclusivos para el modo Arcade. Estética retro premium Triple-A.

## Formato de Carpetas Obligatorio

`NUMERO -Titulo-del-Capitulo-8-bit`

Ejemplo: `1 -Jungla-Tropical-8-bit`

## Requisitos Visuales

1. **Estética 8-bit**: Pixel art de alta fidelidad.
2. **Parallax Extra**: Soporte para hasta 8 capas de profundidad.
3. **Iluminación**: Diseñados para trabajar con el sistema de *God Rays* y *Bloom* del motor Arcade AAA.
